Take Verilog all the way to silicon.

LibreLane is the open-source flow that turns Verilog into a chip layout on SkyWater 130 nm, GF 180 nm MCU and other open processes. LanEx runs it for you, one step at a time, with no terminal.

    Install the toolchain (recommended default)
    
      
    The most reliable way to obtain all required EDA tools (OpenROAD, Yosys, Magic, KLayout, Netgen, Verilator) is the version-matched LibreLane container image. When Docker or Podman is installed, pulling the image enables Container execution without requiring native binary packages. If a container engine is not present, the installer card below sets up Docker or Podman automatically.
    
      
    

      
    Recommended helper utilities (optional)
    
      
    Auxiliary tools used for interactive features: Icarus Verilog provides testbench simulation in the IDE, Graphviz renders synthesis schematics, and GDS3D provides 3D layout visualization. If package installation requires elevated privileges, LanEx prompts for authentication in the terminal.
    
      
    

      
    
        Advanced: local toolchainOnly needed for Local tools run mode (Nix / conda / system installs).
        
    
          
    These binaries are invoked when running with native host tools. Green status indicates the executable was found in PATH. librelane and ciel can be installed via pip; OpenROAD, Magic, and Netgen require installation through Nix, Conda (litex-hub), or container mode.
    
          
    Version compatibility: If an installed native tool is incompatible with your LibreLane release (such as an older Yosys build lacking pyosys bindings), switch to Container mode to execute the exact version-pinned binaries provided in the official image.

    Custom macros advanced
    
          
        
    
        
    Integrate pre-hardened blocks, such as SRAM arrays, PLLs, analog IP, or sub-blocks, as fixed macros in this run. Required physical views (LEF and GDS) along with optional timing and netlist models (LIB, netlist, SPEF, SPICE) are supplied to LibreLane's MACROS variable via GUI overlay parameters, leaving your base config.json unchanged.
    
        
    
      
    

      
    
        
    
          
    Custom cells advanced
    
          
        
    
        
    Substitute proprietary standard cells or custom drive-strength variants for standard PDK library cells during flow execution. Custom cell definitions are passed through EXTRA_LEFS/LIBS/GDS/SPICE_MODELS/VERILOG_MODELS while excluded library cells are specified in EXTRA_EXCLUDED_CELLS, applied dynamically to GUI runs without modifying the underlying config.json.
    
        
    
      
    

      
    Standard-cell library
    
      
    Every cell in the selected PDK's standard-cell library, by kind. Pick the PDK/SCL in Setup.
