INTUITIVE CHIP DESIGN

Keep focus on the silicon architecture,
with an interface built for the flow.

LibreLane provides a capable open-source ASIC flow, though operating it directly requires managing complex YAML configurations, tracking multi-stage steps in text consoles, and parsing raw log files to diagnose failures.

LanEx introduces a visual interface for the entire RTL-to-GDSII pipeline. Every reported metric, timing slack calculation, and DRC summary is read directly from tool output files without alteration.

THE COCKPIT

An integrated ASIC cockpit.

Manage the entire path toward tape-out in a unified interface, coordinating toolchain execution while parsing live logs and signoff metrics.

Live Pipeline

Track every step with live status streaming over SSE. Step failures jump directly to the relevant log lines and diagnostic error messages.

RTL IDE

Edit Verilog and SystemVerilog with syntax highlighting. Run lint checks with Verilator and simulate testbenches using the embedded waveform viewer.

Verification Center

Consolidated signoff summaries for DRC, LVS, antenna checks, and STA timing. Stage verdicts reflect actual run metrics without masking incomplete data.

Analytics & DSE

Plot metric trends across iterations, compare configuration deltas between runs, and evaluate parameter trade-offs on Pareto charts.

Layout Viewers

Inspect GDSII and DEF layouts using KLayout, Magic, GDS3D, or OpenROAD GUI, launched directly with the appropriate PDK layer definitions.

Toolchain Manager

Downloads the version-matched LibreLane container image automatically, or integrates with an existing local toolchain and container runtime.

Compare & Explore: Compare configuration and metric differences between runs, and sweep parameters with DSE.
Cells & Macros: Inspect standard-cell properties, swap cell variants, and integrate hardened macro blocks.
Run History: Filter, pin, export, bundle, and reproduce previous flow runs with persistent metadata.
Auto-Config: Scan source directories to infer top-level modules, clock periods, and file associations for initial configurations.

POWER FEATURES

Precision control.
Down to the polygon.

Visualizing your layout

LanEx launches external layout tools configured with matching PDK techfiles and layer properties. Inspect 2D GDSII structures, review detailed DRC markers, examine placed DEF components, or visualize layer stacks in 3D.

  • KLayout: Fast 2D GDSII and OASIS mask viewer with layer hierarchy inspection.
  • Magic: Interactive VLSI layout tool with real-time DRC checking and extraction.
  • OpenROAD GUI: Interactive viewer for floorplanning, placement rows, CTS trees, and routing tracks.
  • GDS3D: Hardware-accelerated 3D viewer rendering multi-layer metal stacks and vias.

Custom Cells & Macros

Incorporate specialized IP blocks and cell variations into the physical synthesis flow without modifying base configuration files.

Hard Macros

Instantiate pre-hardened SRAMs, analog IP, or external PHYs. Supply the LEF and GDS files, specify pin locations, and LibreLane routes interconnect automatically.

Custom Cells

Include custom clock-gating cells, specialized delay cells, or hand-crafted logic gates by supplying Liberty timing definitions and physical LEF layouts alongside the PDK.

FIVE CLICKS TO SILICON

Clear flow execution.
From source RTL to final GDSII.

Every underlying invocation is fully transparent. Use the CLI panel to inspect the exact commands executed, with metrics reported directly from tool outputs.

01

Pick your design

Point LanEx at your HDL directory, or load the built-in SPM multiplier design. Auto-detection extracts top modules and clock ports.

02

Confirm your PDK

Select your process design kit and standard-cell library. LanEx detects local installations and indicates any missing libraries.

03

Choose your mode

Run the entire flow end-to-end automatically, or use Step-by-step mode to pause and review stage outputs between steps.

04

Press Run

Monitor pipeline progress in real time across synthesis, floorplanning, placement, clock tree synthesis, routing, and tape-out.

05

See your chip

Inspect generated GDSII files, verify DRC and LVS reports, review timing slack margins, and compare results across runs.

INSTALL

One cockpit.
Every platform.

Packaged as a lightweight Python application. Heavy EDA tools execute inside the official container image or via an existing local installation. Python ≥ 3.10 required. Windows supported via WSL2.

Universal script (Linux, macOS, WSL2)

Installs LanEx and prerequisites on Linux, WSL2, or macOS. Re-run the command at any time to update to the latest release.

curl -fsSL https://raw.githubusercontent.com/AkshatIsWired/lanex/main/scripts/install.sh | bash
lanex

macOS (Manual)

Requires Python ≥ 3.10. A container engine is recommended to execute EDA tools inside the managed container image.

brew install pipx
pipx ensurepath; export PATH="$HOME/.local/bin:$PATH"
pipx install https://github.com/AkshatIsWired/lanex/archive/refs/heads/main.tar.gz
lanex

Fedora / Arch (Manual)

pipx with Mesa GL drivers. Tested on Fedora, Arch Linux, CentOS Stream, and related distributions.

sudo dnf install -y pipx git mesa-dri-drivers xorg-x11-fonts-misc
pipx ensurepath; export PATH="$HOME/.local/bin:$PATH"
pipx install https://github.com/AkshatIsWired/lanex/archive/refs/heads/main.tar.gz
lanex

Existing LibreLane env

If LibreLane is already installed in an active virtualenv or Conda environment, install LanEx directly to utilize your existing toolchain.

git clone https://github.com/AkshatIsWired/lanex && cd lanex
pip install .
lanex

For Arch Linux, install dependencies with sudo pacman -S --needed python-pipx git mesa, then proceed with the pipx installation. If Docker or Podman is not already installed, the in-app Tools tab provides guided installation. After setup, pull the version-matched LibreLane image directly from the Tools tab.
