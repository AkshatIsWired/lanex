New test build. Install it over the old one: your projects, runs and PDKs are kept.

**Download:** `LanEx-Setup.exe` below. Windows will say "Windows protected your PC" (not code-signed yet). Click **More info**, then **Run anyway**.

## New since the last build

- **First launch is like a game's.** A "Press Start" card asks how you want to begin:
  - **Make my first chip:** a guide that builds the Blinky example with you, one step at a time (simulate, pick a PDK, change a setting, run, see the layout in 2D and 3D). Each step moves on when you actually do it, and you finish on a card with your real numbers.
  - **Show me around:** a 5-stop tour of where things are.
  - **I know LibreLane:** skip.

  You can open either one again later from Help or Ctrl+K.
- **Runs page rebuilt.** One sortable table with timing, area, power, DRC and runtime for every run.
  - Star a run as the baseline and every other number turns green or red against it.
  - Tick 2 to 6 runs to compare them.
  - Fix runs show which run they came from.
- **Sweeps live in Runs now** (the DSE tab is gone). Click **New sweep**, pick a goal like "try 3 clock speeds", and the sweep shows up as one grouped row. Failed points say why, and the summary tells you which point was best for timing and which for area.
- **Console (Ctrl+`) replaces Manual.** A drawer at the bottom of every page with:
  - the live log
  - the exact command each run used
  - a "reproduce without LanEx" script (paste it in a terminal and you get the same chip)
  - a journal of what you did, which you can copy as a script
- **Tools page redone.** You can see at a glance whether everything is ready. If something isn't, it's at the top with a fix button. Docker and the LibreLane image are the main card, PDKs are grouped by family, and each viewer or helper says what in LanEx uses it.
- **Ctrl+K searches more.** Type `#` for settings, `@` for runs, `/` for files, `?` for help, `>` for actions.

## Fixed

- **Every tab agrees on how a run went.** Before, Analytics could say "all checks passed" while Verify said "not enough to call it". Running and stopped runs no longer show as failed.
- **A missed timing corner is a warning, not "clean".** The status bar and pop-ups used to say clean anyway.
- **The blank template works for real designs.** It had a tiny fixed chip size, so placement failed; it now sizes itself to the design.
- **gf180 "PDK not found" from the Console command is fixed.** The command now always names the project's PDK.
- **Nothing runs into a missing project folder.** If you rename or delete the folder while LanEx is open, Run, Resume and sweeps stop and tell you what happened.
- **Lint and syntax problems show up before the run.** The IDE now flags latches and loops the same way the flow does, a syntax error warns you before you press Run, and the error shows the file and line.
- **The fix sheet gives better advice** for slew warnings. Its top suggestion now actually clears them.
- **Step numbers match everywhere** (header, list and run folder).
- **Times are in your local time,** not UTC.
- **The run list is much faster:** 300 runs now load in under 2 seconds instead of about 30.
- **Security:**
  - Another website can't take over LanEx through your browser.
  - A shared run can't hide commands inside "Copy as script".
  - The Console only runs safe commands.

## Please try

1. Install over the old build. On first launch pick **Make my first chip** and follow it to the end.
2. Make a new project from the blank template with your own Verilog and run it.
3. On Runs, star a run as the baseline, then click **New sweep** and try 3 clock speeds.
4. Press Ctrl+` and copy the "Reproduce" script for a run.
5. Open Tools and check it says everything is ready.

Something broke? Open an issue and attach `%LOCALAPPDATA%\LanEx\logs\install.log` and `launcher.log`, plus a screenshot.

Needs Windows 11 (or Windows 10 22H2), 8 GB RAM and about 23 GB free.
