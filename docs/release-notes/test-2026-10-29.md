## Layout tab redesign (new 2026-10-29)

The Layout tab is where you see your chip, so it got a full makeover.

- **The 3D view looks far better.** Soft studio lighting, a dark backdrop with a micron grid and a shadow under the chip, thin outlines and a bit of depth haze. There's a white version too (the background button).
- **Pick the colours:** LanEx (each layer job gets its own colour, the same on every PDK), Metallic (copper and gold), or PDK (the foundry's own colours).
- **Better starting view.** Spread starts at 70% so you can see each layer, and height starts low and depends on chip size. Both sliders show their value. Height x1 with spread 0% is the real stack.
- **A chip rises from the flat picture into 3D** when it opens (Reset plays it again). There's an optional slow Turntable spin.
- **Big chips open in 3D now.** A 12,000-cell design used to come out garbled. Now the whole chip shows, with a note that the densest lower layers are hidden until you zoom in.
- Cleaner layer list (plain names like `met1`), clearer presets, one tidy controls card, a cleaner stage strip.

Also: the PDK cards on Tools sit in two even columns.

## What changed: LanEx is fast now, on any PC

The goal was for LanEx to feel instant on a strong PC and still smooth on a cheap laptop. We timed everything before and after, on this PC and with the processor slowed down 6 times to act like a low-end laptop.

| What you do | Before | Now | Now on a slow laptop (6x slower CPU) |
|---|---|---|---|
| Press **Run** until the run page shows | about 2 seconds | instant (under 0.01 s) | about 0.02 s |
| Open the app (window shows) | 0.8 s | 0.1 s | 0.7 s (was 1.6 s) |
| Reload the page | 0.6 s, downloads 1.9 MB | 0.07 s, downloads 20 KB | 0.4 s |
| Open the Runs page with 300 runs | 2.3 s | 0.06 s | 0.5 s (was 4.3 s) |
| Open Tools | 1.7 s | 0.04 s | 0.4 s |
| Open a project with 300 runs | about 8 s | instant | |
| Open a project on the C: drive (`/mnt/c`) | about 23 s | 0.07 s | |
| Memory the app uses | 608 MB | 258 MB | |

What that means in practice:

- **Run doesn't hang any more.** The run page opens the moment you click, says "Starting", and Stop works straight away, even before LibreLane has started.
- **The app opens almost immediately.** It only loads the page you're on. The charts library and the other pages load when you first open them.
- **Pages show a loading placeholder** (a soft pulsing outline of the page) if they take more than a moment, and keep the old content on screen while new data arrives, so nothing flashes blank. If your PC is set to reduce motion, the pulse is off.
- **Long runs stay smooth.** The live log adds only the new lines, and the run page redraws about 8 times less while a run is going.
- **Big projects are fine.** The Runs table only draws the rows you can see. Large waveforms load in the background with a progress bar, and typing in the editor stays quick in big files.
- **Uses less of your PC when idle**, so it's easier on laptop batteries.

## Runs are sized to your PC

LibreLane normally uses every CPU core for routing, DRC and timing. On a PC with lots of cores that can use a lot of memory (and the router has crashed with 32 threads). On a small laptop it can run out of memory.

LanEx now picks the thread counts from your cores and free memory when a run starts:
- routing gets at most 16 threads;
- DRC gets at most 8, or 2 when memory is low;
- timing only checks as many corners at once as memory allows.

**The results are exactly the same.** We checked every final number on two designs. Only the speed and memory use change.

- If you set these numbers in your config yourself, yours are used.
- The run's command and the "Reproduce" script carry the chosen numbers, so they give the same result.
- To turn this off, put `"thread_sizing": false` in `settings.json`.

Before a run, LanEx also warns you if free memory looks too small for the design.

## Fixed

- **Stop while starting.** If you stopped a run before it really began, the run page used to show an older run's result. Now it says "The run didn't start" and offers Try again.
- **Two windows.** With LanEx open in two windows, the second one showed Run during a run, and pressing it stopped that run. Both now show Stop.
- The Stop button no longer turns blue when you hover over it.
- Faster config check for projects kept on the C: drive.
